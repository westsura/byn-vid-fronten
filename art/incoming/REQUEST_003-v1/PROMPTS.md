# Bildarbete och animation

Benkomponenterna skapades med inbyggd imagegen. Den godkända redo-bilden återanvänds oförändrad som övre lager. Benkomponenterna placeras och roteras under kroppen med Canvas för åtta sträckbestämda steg; atlasen och den markerade remsan exporteras från samma rendering. Ingen ny utrustning eller omritad överkropp.

## Bildprompt

Create animation component artwork matching the attached German overhead soldier reference. Transparent square canvas1254x1254. ONLY TWO SEPARATE detached straight trousered leg-and-boot components, no body, no head, no arms, no weapons, no shadows, no labels. TOP leg horizontally from hip-cut LEFT at x180,y340 to brown boot toe RIGHT x1060,y340. BOTTOM leg horizontally same from x180,y900 to x1060,y900, opposite anatomical leg. Each leg is slim, straight in orthographic DIRECT OVERHEAD camera: grey field trousers with subtle cloth folds, narrow knee, lower leg, brown leather lace-up ankle boot. Match EXACT reference grey pants and brown boot material/style. Each component about850px long and120px wide, isolated and separated by generous transparent padding. This is a rigging texture, not a full soldier. No circular hip joints or diagram. Hip-to-knee around400px, knee-to-ankle320px, boot at right end. Toe points RIGHT. Preserve true alpha.
