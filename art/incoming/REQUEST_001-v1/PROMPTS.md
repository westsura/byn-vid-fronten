# Bildgenerering

Metod: inbyggd imagegen, referensbaserad nygenerering. Referenser: husets kartutsnitt och husets geometri ur REQUEST_001. Råresultaten hade andra pixelmått än begärt; slutleveranserna har därför bearbetats och registrerats med kod efter Björns godkännande. Soldater och UI är SVG/HTML, inte AI-raster.

## Tak

Create a single production game sprite, not a presentation. Asset: standalone orthographic top-down slate ROOF of the supplied Normandy farmhouse reference. Preserve reference material, gray slate tile sizes, weathering and light from upper left. Entire output canvas EXACTLY 524x460 pixels with genuine transparent alpha outside roof, NO checkerboard painted in, no ground or labels. The registered building rectangle is x32..492 y32..428 in this canvas. Roof must cover that entire rectangle, eaves may extend 8 pixels outside it, but remain within canvas. Main ridge horizontal, main roof as near rectangular shape, slight southeast subsidiary roof within main rectangle, one small chimney NE like reference. Strict straight 90 degree overhead view, no perspective; detailed painterly realistic slate to integrate into reference map. IMPORTANT size and placement, asymmetric registration is intentional. No UI, text, border, soldiers. Output only transparent roof asset. Reference image 1 is material/style reference, image 2 is geometry reference; do not render annotations. Save output for use as PNG.

Canvas EXACTLY 524x460 px, real transparent background outside footprint. No text, markers, dimensions, grid, ground, figures or checkerboard. Exact registration: outside edges of rectangular house x32 to492, y32 to428; walls 24px thick inward. Pale warm limestone cutaway perimeter wall. North wall window GAP x198 to326, y32 to56. West wall window GAP x32 to56, y166 to294. East wall window GAP x468 to492, y166 to294. South wall OPEN DOOR x220 to372, y404 to428, with low stone threshold extending no further than y448. These FOUR openings are the only perimeter openings; perfectly align them. Windows have low dark sills, but no solid wall across opening; door open. Interior mostly empty warm pale oak plank floor, subtle aged texture, NO internal walls or dividers, NO rugs. Tiny storage furnishing only tucked tightly into NW and SE inside corners: one low wooden chest and one small shelf, leaving all center and window access free. Lighting soft from upper left, no dark interior shadow bands resembling impassable walls. Reference geometry is mandatory and reference photo supplies style. Texture realism without unnecessary clutter. No roof. Produce transparent PNG asset.
